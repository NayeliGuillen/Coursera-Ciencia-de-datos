Lenguajes de Ciencia de Datos

Python, R y SQL son los pilares. Elige según tu rol y necesidades.

¿Cuál aprender primero?

Depende de tu rol, los problemas que resuelves y la empresa donde trabajas. Recomendación: Python → SQL → R para la mayoría de roles en DS.

Python

#1 en DS

El más popular. Sintaxis clara y legible. Usado por IBM, Google, NASA, Facebook. 80%+ de profesionales DS lo usan.

Librerías DS clave:

PandasNumPyMatplotlibScikit-learnTensorFlowPyTorch
PyLadies y Python Software Foundation promueven diversidad e inclusión en la comunidad.

R

Software libre

Popular en academia, salud y estadística. Sintaxis orientada a arrays. 15,000+ paquetes públicos. Se aprende típicamente después de Python.

Paquetes DS clave:

dplyrggplot2caretstringrKeras (R)
Open Source vs Free Software: Python es open source (OSI), R es free software (FSF). Diferencia en valores y enfoque.

SQL

Esencial

No es un lenguaje de programación tradicional — es un lenguaje no procedural para consultar y gestionar datos. Existe desde 1974. Desarrollado por IBM.

Bases de datos:

MySQLPostgreSQLIBM Db2SQLiteSQL Server
SQL es estándar ANSI: aprenderlo en una base de datos te permite usarlo en casi cualquier otra.

Otros lenguajes relevantes

Scala

Base de Apache Spark. Combina Java y programación funcional. Muy usado en data engineering.

Java

Base de Hadoop. Herramientas: Weka, Java-ML, Apache MLlib, Deeplearning4j.

Julia

Diseñado en MIT para análisis numérico. Tan rápido como C, tan fácil como Python. Futuro prometedor.

JavaScript

TensorFlow.js: ML en el navegador. R-js: álgebra lineal de R en TypeScript.

Librerías y APIs

Colecciones de funciones que evitan escribir código desde cero.

Librerías Python para DS

Pandas🇺🇸 Pandas — Librería Python para manipulación y análisis de datos. Proporciona DataFrames: tablas de filas y columnas. Base del trabajo diario en DS.

Cómputo científico

Estructuras de datos y herramientas para limpieza, manipulación y análisis. Instrumento principal: el DataFrame (tabla 2D). Construido sobre NumPy.

NumPy🇺🇸 NumPy — Librería Python para cómputo numérico con arrays y matrices. Pandas está construido sobre NumPy.

Cómputo científico

Arrays y matrices multidimensionales. Permite aplicar funciones matemáticas eficientemente. Base de casi toda la ciencia de datos en Python.

Matplotlib🇺🇸 Matplotlib — Librería Python más conocida para visualización de datos. Crea gráficas y plots personalizables.

Visualización

La librería de visualización más conocida. Gráficas y plots fácilmente personalizables: líneas, barras, dispersión, histogramas.

Seaborn

Visualización

Basada en Matplotlib. Genera heat maps, series de tiempo y violin plots con menos código. Más estética que Matplotlib.

Scikit-learn🇺🇸 Scikit-learn — Librería Python de Machine Learning de alto nivel. Incluye regresión, clasificación, clustering. Construida sobre NumPy, SciPy y Matplotlib.

Machine Learning

Herramientas para modelado estadístico: regresión, clasificación, clustering. Alto nivel: defines el modelo y los parámetros. Construida sobre NumPy, SciPy, Matplotlib.

TensorFlow🇺🇸 TensorFlow — Framework de bajo nivel para Deep Learning a gran escala. Diseñado para producción. Desarrollado por Google. Escrito en C++, API en Python.

Deep Learning

Framework de bajo nivel para producción de modelos de deep learning a gran escala. Escrito en C++, usado vía Python. Desarrollado por Google.

PyTorch🇺🇸 PyTorch — Framework de Deep Learning para experimentación e investigación. Más flexible que TensorFlow para probar ideas nuevas. Desarrollado por Facebook.

Deep Learning

Para experimentación e investigación. Más simple y flexible para probar ideas. Complemento de TensorFlow en el ecosistema de DL.

Keras

Deep Learning

Interfaz de alto nivel para construir modelos de deep learning. Rápido y simple. Puede usar GPU. Para prototipado rápido antes de pasar a TensorFlow.

Apache Spark🇺🇸 Apache Spark — Framework de cómputo distribuido en clústeres. Procesa datos en paralelo en múltiples máquinas. Soporta Python, R, Scala y SQL.

Big Data

Procesa datos en paralelo en clústeres. Similar a Pandas + NumPy + Scikit-learn pero a escala masiva. Soporta Python, R, Scala, SQL.

APIs y REST APIs

¿Qué es una API🇺🇸 API (Application Programming Interface) — Interfaz que permite la comunicación entre dos piezas de software. Define entradas y salidas sin exponer cómo funciona internamente.?

Permite la comunicación entre dos piezas de software. Solo ves la interfaz (entradas/salidas), no el interior. Ej: la API de Pandas te permite usar sus funciones sin saber que parte está en C.

Analogía: El menú de un restaurante es la API — te dice qué pedir y qué recibirás, sin que veas la cocina.

REST APIs

REpresentational State Transfer. Permiten comunicarse a través de internet usando HTTP.

ClienteTu programa
EndpointURL de la API
RequestLo que envías (JSON)
ResponseLo que recibes (JSON)

Ej: Watson Speech-to-Text API recibe audio → devuelve texto transcrito.

Módulo 3 · Parte B

Datasets y Modelos ML

La materia prima de la Ciencia de Datos y cómo los modelos aprenden.

¿Qué es un Dataset🇺🇸 Dataset — Colección estructurada de datos. Puede ser tabular (CSV), jerárquica, en red, o archivos crudos como imágenes o audio.?

Colección estructurada de datos. Puede ser tabular (CSV), jerárquica (árbol), en red (grafo), o archivos crudos (imágenes, audio).

CSV: Cada fila = observación, cada columna = característica. Formato más común.
MNIST: 70,000 imágenes de dígitos escritos a mano. El "Hello World" de la visión por computadora.
Open Data: ONU, UE, gobiernos publican datos abiertos en datacatalogs.org, Kaggle, Google Dataset Search.

Licencias de Datos Abiertos

La Linux Foundation creó la CDLA (Community Data License Agreement) para datos abiertos.

CDLA-Sharing: Puedes usar y modificar, pero si publicas tus cambios debes usar la misma licencia.
CDLA-Permissive: Puedes usar y modificar. No estás obligado a compartir tus cambios.

Ambas: ninguna restricción sobre los resultados del análisis (tus modelos).

Tipos de Modelos ML

Supervisado

Aprendizaje supervisado / Supervised Learning

Datos etiquetados. El modelo aprende relación entrada→salida.

Regresión: predice valor numérico (precio, salario)
Clasificación: predice categoría (spam, enfermedad)

No Supervisado

Unsupervised Learning

Sin etiquetas. Descubre estructura por sí solo.

Clustering: grupos por similitud (recomendaciones)
Anomalías: fraude, intentos de hackeo

Refuerzo

Reinforcement Learning

Prueba y error con recompensas. Aprende la mejor secuencia de acciones.

Ej: AlphaGo, coches autónomos, videojuegos.

Model Asset eXchange (MAX) — IBM

Repositorio gratuito open source de modelos de Deep Learning listos para usar. Reduce el tiempo de entrenamiento aprovechando modelos pre-entrenados.

Categorías:
Detección de objetos, audio, texto, poses humanas, más.
Tecnología:
Distribuidos como imágenes Docker en GitHub. Desplegables en Kubernetes / OpenShift.
Licencia:
Open source permisiva — uso personal y comercial permitido.

Jupyter Project

El entorno de desarrollo más popular entre científicos de datos.

¿Qué es Jupyter?

Un cuaderno interactivo (notebook) que combina código ejecutable, texto descriptivo, visualizaciones y ecuaciones en un solo documento. El nombre viene de Julia + Python + R. Soporta 100+ lenguajes vía kernels.

Jupyter Notebook🇺🇸 Jupyter Notebook — Aplicación web que permite crear documentos con código, texto, visualizaciones y ecuaciones. El estándar para DS interactivo.

Aplicación basada en navegador. Celdas de código y Markdown. Genera outputs (tablas, gráficas) dentro del documento. Exportable a HTML, PDF.

"Como el cuaderno de laboratorio de un científico: registra cada paso y resultado reproducible."

JupyterLab🇺🇸 JupyterLab — La próxima versión de Jupyter. Más modular y flexible. Permite abrir múltiples notebooks, terminales y archivos simultáneamente.

La versión siguiente de Jupyter Notebooks. Más modular. Permite abrir múltiples notebooks, terminales y tipos de archivo simultáneamente en un canvas flexible.

Kernels: el motor de ejecución

El kernel🇺🇸 Kernel — Motor computacional que ejecuta el código en un notebook. Hay kernels para Python, R, Julia, Scala y más de 100 lenguajes. es el motor que ejecuta el código. Un notebook = un lenguaje = un kernel.

RStudio y GitHub

El IDE de R y el control de versiones esencial para todo DS.

RStudio

IDE popular para R (desde 2011). Unifica programación, ejecución, depuración, visualización y más en un solo entorno.

Editor de código con syntax highlighting y ejecución directa
Consola R para comandos en tiempo real
Workspace muestra objetos R creados en sesión
Plots, Packages, Help en paneles dedicados

Visualización en R: ggplot2

La librería más popular de visualización en R. Agrega capas y funciones para crear gráficas complejas con elegancia.

ggplot2: histogramas, scatter, bar charts con capas
Plotly: visualizaciones web interactivas
Lattice: datasets multivariables complejos
Leaflet: plots interactivos y mapas

Git y GitHub

Git🇺🇸 Git — Sistema de control de versiones distribuido. Permite rastrear cambios en código, colaborar con otros y mantener historial completo del proyecto. es el estándar de facto para control de versiones. Creado por Linus Torvalds en 2005. Cada desarrollador tiene copia local del historial completo.

git clone — clonar repositorio
git add — añadir cambios al staging
git commit — confirmar cambios
git push — subir al repositorio remoto
git merge — fusionar ramas

Ramas y Pull Requests

main

Rama principal. Código desplegable y estable. No tocar sin revisión.

branch

Copia del main para desarrollar sin afectar producción.

PR

Pull Request🇺🇸 Pull Request (PR) — Solicitud para que otro revise y apruebe tus cambios antes de fusionarlos con la rama principal. Base de la colaboración en GitHub.: pide que otros revisen y aprueben antes de fusionar.
