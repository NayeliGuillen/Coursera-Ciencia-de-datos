Módulo 1

Definiendo la Ciencia de Datos

Un campo sobre procesos y sistemas para extraer valor de los datos.

¿Qué es la Ciencia de Datos🇪🇸 Ciencia de Datos / 🇺🇸 Data Science — Campo de estudio que usa procesos y sistemas para extraer conocimiento e insights de datos estructurados y no estructurados.?

Proceso, no evento

"Es el proceso de usar datos para entender el mundo." Incluye formulación de hipótesis y validación con datos reales.

Arte de descubrir insights

"El arte de descubrir los insights y tendencias que se esconden detrás de los datos. Traducir datos en historia."

Curiosidad + datos

"Si tienes datos y curiosidad, el solo hecho de analizar y explorar los datos para obtener respuestas es ciencia de datos."

"Nunca ha habido un mejor momento para ser científico de datos." — Por qué: herramientas baratas, software open source, y datos disponibles en abundancia.

¿Por qué es relevante HOY?

  • ✓Datos disponibles: Antes nos preocupaba la falta de datos. Ahora hay un diluvio de datos.
  • ✓Algoritmos: Antes no había. Ahora hay muchos y maduros.
  • ✓Software: Antes era caro. Ahora es open source🇺🇸 Open Source / 🇪🇸 Código Abierto — Software cuyo código fuente está disponible públicamente para su uso y modificación. y gratuito.
  • ✓Almacenamiento: Almacenar grandes cantidades de datos ahora cuesta muy poco.

Machine Learning, IA y Aprendizaje Profundo

Cómo las máquinas aprenden a reconocer patrones y hacer predicciones.

Machine Learning🇺🇸 Machine Learning / 🇪🇸 Aprendizaje Automático — Rama de la IA que usa algoritmos (modelos) para identificar patrones en datos sin ser programada explícitamente.

Usa algoritmos (modelos) para identificar patrones en datos. El modelo aprende de datos históricos.

Proceso: Datos → Entrenamiento del modelo → Predicciones sobre datos nuevos

Deep Learning🇺🇸 Deep Learning / 🇪🇸 Aprendizaje Profundo — Tipo especializado de ML que usa redes neuronales con múltiples capas para resolver problemas complejos.

Tipo especializado de ML. Emula cómo funciona el cerebro humano. Usa redes neuronales con múltiples capas.

Requiere: Grandes datasets etiquetados + poder computacional + tiempo de entrenamiento

Inteligencia Artificial (IA)

Campo más amplio. ML es una rama de IA. Deep Learning es una rama de ML.

Tipos de Machine Learning

Supervisado / Supervised

Un humano proporciona datos de entrada + respuestas correctas. El modelo aprende la relación.

Regresión: predice valor numérico (precio, temperatura)
Clasificación: predice categoría (spam/no spam, enfermo/sano)
No Supervisado / Unsupervised

Los datos NO están etiquetados. El modelo descubre patrones por sí solo.

Clustering: agrupa datos similares
Detección de anomalías: fraude, intrusiones
Refuerzo / Reinforcement

El modelo aprende por prueba y error. Recibe recompensas por acciones correctas.

Ejemplo: Un ratón en un laberinto que busca queso. AlphaGo dominando al Go.

📖 Lectura del Curso: ¿Por qué los padres altos no siempre tienen hijos más altos?

Fuente: Getting Started with Data Science — Murtaza Haider, IBM Press · Cap. 7 "Why Tall Parents Don't Have Even Taller Children"

El autor analizó 500,000+ transacciones inmobiliarias en Toronto para su tesis de doctorado. Quería predecir precios de casas con regresión.

Al terminar su defensa, una señora al subir al auto le dijo: "¿Por qué les pagan tanto? Solo están confirmando lo que ya sabemos: que las casas más grandes cuestan más."

Su respuesta: "El valor real de la investigación no es confirmar lo obvio, sino cuantificar la magnitud de la relación." ¿En cuánto sube el precio por cada habitación adicional? La regresión responde eso exactamente.

¿Qué puede predecir la regresión?

  • • ¿Cuánto cuesta una casa con baño adicional?
  • • ¿En cuánto aumenta el precio por cercanía al metro?
  • • ¿Cuánto vale un acabado de piedra vs ladrillo?
  • • Predicción de salarios, demanda, temperatura, ventas

¿Por qué "regresión a la media"?

Los hijos de padres muy altos tienden a ser altos, pero no tan altos como sus padres. Los datos regresan hacia el promedio. Este fenómeno estadístico dio nombre al algoritmo.

Big Data y Minería de Datos

Las 5 V's y las herramientas para procesar datos masivos.

¿Qué es Big Data🇺🇸 Big Data — Volúmenes masivos de datos dinámicos y diversos generados por personas, herramientas y máquinas. Requiere tecnología nueva y escalable para procesarlos.?

Ernst & Young: "Big Data se refiere a los volúmenes dinámicos, grandes y dispares de datos creados por personas, herramientas y máquinas. Requiere tecnología nueva, innovadora y escalable para recopilar, hospedar y procesar analíticamente la vasta cantidad de datos."

Las 5 V's del Big Data

V

Velocity

Velocidad a la que se acumulan los datos. Near real-time. Ej: YouTube recibe horas de video cada 60 segundos.

V

Volume

Escala de los datos. 2.5 quintillones de bytes diarios. Infraestructura escalable necesaria.

V

Variety

Diversidad: datos estructurados (tablas) vs no estructurados (tweets, fotos, video).

V

Veracity

Calidad y origen de los datos. Consistencia, integridad, exactitud. ¿Son reales o falsos?

V

Value

Capacidad de convertir datos en valor. No solo dinero: beneficios médicos, sociales, satisfacción.

Herramientas para Big Data

Hadoop🇺🇸 Hadoop — Framework de Apache para almacenamiento distribuido (HDFS) y procesamiento de Big Data en clústeres de servidores. Escrito en Java.

Framework Apache para almacenamiento distribuido y procesamiento. HDFS = Hadoop Distributed File System. Diseñado para escalar horizontalmente.

Maneja el procesamiento y almacenamiento para aplicaciones de Big Data en sistemas de clúster.

Apache Spark🇺🇸 Apache Spark — Motor de procesamiento rápido y de propósito general para Big Data. Diseñado para ser hasta 100x más rápido que Hadoop MapReduce en memoria.

Procesamiento en memoria, mucho más rápido que Hadoop. Soporta Python, R, Scala, SQL. Ideal para ML a escala.

Diseñado para ser más rápido que Hadoop. Procesa en memoria (RAM) en lugar de disco.

Apache Hive

Data warehouse sobre Hadoop. Permite consultas tipo SQL sobre grandes datasets. Ideal para analistas que ya saben SQL.

HiveQL es un lenguaje de consulta similar a SQL pero para datos masivos en Hadoop.

Proceso de Minería de Datos / Data Mining Process

Fuente: Introducción a la Ciencia de Datos — Murtaza Haider, IBM Press · Cap. 12, pág. 529–531

El primer paso es establecer objetivos: identificar las preguntas clave, los costos y beneficios, y el nivel de precisión esperado. El intercambio costo-beneficio siempre determina el alcance del ejercicio.

1. Selección de Datos / Data Selection

La calidad de los resultados depende de la calidad de los datos. A veces están disponibles directamente (ej. minoristas con grandes bases de compras), pero otras veces debes identificar fuentes alternativas o planificar nuevas recolecciones, incluidas encuestas.

Clave: El tipo de datos, su tamaño y la frecuencia de recolección impactan directamente el costo. Identificar el tipo correcto de datos es fundamental antes de comenzar.

2. Preprocesamiento de Datos / Data Preprocessing

Los datos en bruto son frecuentemente desordenados: erróneos, irrelevantes o incompletos. En esta etapa se identifican y eliminan atributos irrelevantes, se marcan errores y se desarrolla un método formal para tratar los datos faltantes.

Datos faltantes aleatorios: Un conjunto simple de soluciones es suficiente (imputación con media/mediana).
Datos faltantes sistemáticos: Debes determinar el impacto. Ej: si todos los de altos ingresos no reportaron su salario, excluirlos genera sesgo sistemático en el análisis.

3. Transformación de Datos / Data Transformation

Determinar el formato apropiado para almacenar los datos. El objetivo es reducir atributos sin perder información significativa usando técnicas como el Análisis de Componentes Principales (PCA).

Ejemplo práctico: El ingreso de un individuo puede estar dividido en: salario, renta de propiedades, apoyos gubernamentales. Sumar todas las fuentes crea un indicador representativo del ingreso total. También puede convenir transformar una variable continua (ingreso) en categórica (bajo/medio/alto) para capturar no linealidades.

4. Almacenamiento de Datos / Data Storage

Los datos transformados deben almacenarse en un formato que otorgue acceso eficiente de lectura/escritura. Durante la minería se crean nuevas variables que se escriben de vuelta en la base original, por lo que el esquema de almacenamiento debe soportarlo.

Principio clave: La seguridad y privacidad de los datos deben ser una preocupación principal. Los datos no deben estar dispersos en diferentes servidores, ya que el algoritmo perdería tiempo buscándolos.

5. Minería de Datos / Data Mining

Una vez que los datos están procesados y almacenados, se aplican métodos de análisis: métodos paramétricos y no paramétricos y algoritmos de aprendizaje automático.

Punto de partida recomendado: La visualización de datos. Las vistas multidimensionales son muy útiles para desarrollar una comprensión preliminar de las tendencias ocultas en el dataset antes de aplicar algoritmos.

6. Evaluación de Resultados / Results Evaluation

Se realiza una evaluación formal de la capacidad predictiva de los modelos — qué tan efectivos han sido los algoritmos en reproducir datos conocidos ("pronóstico en muestra"). Los resultados se comparten con stakeholders para obtener retroalimentación.

Proceso iterativo: La minería de datos y la evaluación se repiten en ciclos. Los analistas utilizan algoritmos mejorados a la luz de los comentarios recibidos de las partes interesadas clave.
